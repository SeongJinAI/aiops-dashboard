# Nova 라이브 데모 스크립트 — Track → Wikify → Coach

> 발표 덱 11번 슬라이드("실제로 보여드리겠습니다")에서 이 데모로 전환한다. 데모 후 12번(어떻게 만들었나)부터 이어서 발표.
> 목표 시간: **5~6분**. 핵심은 "흩어진 흔적 → 자산 → 다음 한 걸음"의 흐름을 눈으로 보여주는 것.

## 0. 사전 점검 (발표 시작 전, 1회)

```bash
# 1) 백엔드 (saas 모드, 실데이터 DB)
cd /mnt/c/Personal/aiops-dashboard/server
AIOPS_MODE=saas DB_PATH=./data/aiops_saas.db python3 -m uvicorn main:app --host 0.0.0.0 --port 8000

# 2) 프론트엔드 (별도 터미널)
cd /mnt/c/Personal/aiops-dashboard/frontend
npm run dev -- --host 0.0.0.0
```

- [ ] `http://localhost:8000/api/mode` → `{"mode":"saas","auth_required":true}` 확인
- [ ] `http://localhost:5173` 접속 → **로그인** (JWT는 24h 만료 → 발표 당일 재로그인 필수)
- [ ] 로그인 후 사이드바에 **Agent 섹션 > 코치** 항목이 보이는지 확인
- [ ] **코치** 페이지 미리 한 번 열어 점수(85·B)가 뜨는지 확인 (첫 로드 캐시)
- [ ] 화면 밝기/해상도, 폰트 키우기(브라우저 Ctrl+`+`로 110~125%), 다크/라이트 중 발표장 조명에 맞게 선택
- [ ] 폴백: 네트워크/서버 문제 시 → 덱 10번 슬라이드의 Coach UI 재현 화면으로 설명 대체

## 1. Track — "일단 전부 모입니다" (90초)

**이동:** 사이드바 → **홈** → **프롬프트**

**홈에서 (10초):**
> "이건 제가 평소 AI랑 일한 흔적이 전부 자동으로 쌓인 화면입니다. 제가 따로 기록한 게 아니라, Hook 한 줄 깔아두면 알아서 모입니다."

- 상단 stat 카드: 프롬프트, Hook 전체, Hook 성공률(100%), 평균 토큰 가리키기

**프롬프트 탭에서 (60초):**
> "여기서부터가 재밌습니다. 1,056개 프롬프트의 시간대 분포예요."

- **시간대별 활동 · 24h** 막대 가리키며:
> "보세요. 새벽엔 아예 안 하고, 오전 9시에 켜서 **16시에 가장 깊게 몰입**합니다. 174건. 이게 막연한 느낌이 아니라 숫자로 나오는 거죠."

- **길이 분포** 가리키며:
> "그리고 제 프롬프트의 85%가 100토큰 이하예요. 짧게 자주 던지는 스타일이라는 걸, 데이터가 알려줍니다."

> "AI 협업을 '잘하고 있나?'는 느낌이 아니라 측정 대상이 됩니다. — 이게 1단계, **Track**."

## 2. Wikify — "컨텍스트를 자산으로" (90초)

**이동:** 사이드바 → **Agent > 에이전트**

> "두 번째 문제. AI한테 같은 설명을 매번 반복하잖아요. 프로젝트 구조, 규칙, 왜 이렇게 짰는지…"

> "그래서 만든 게 이 에이전트입니다. 흩어진 마크다운 문서를 — 제 프로젝트는 252개였는데 — **기획자·개발자·사용자 세 관점의 위키로 자동 정리**해줍니다."

- (위키가 이미 생성돼 있으면) perspective 탭 전환하며 본문 보여주기
- **버전 히스토리 / diff** 버튼 가리키며:
> "버전 관리도 됩니다. 어제 위키랑 오늘 위키가 뭐가 달라졌는지 자동으로 요약해줘요."

> "흩어진 인사이트가 **공유 가능한 자산**이 되는 거죠. — 2단계, **Wikify**."

> ⚠️ (라이브 위키 빌드는 LLM 호출이라 시간/크레딧 소요 → 발표에선 **이미 생성된 결과**를 보여주고, 빌드 과정은 덱 8번 슬라이드로 설명. 시간 여유 있으면 [에이전트 업데이트] 눌러 progress bar만 시연.)

## 3. Coach — "그래서 뭘 개선하죠?" (2분, 클라이맥스)

**이동:** 사이드바 → **Agent > 코치**

> "그런데 여기서 진짜 질문이 나옵니다. 데이터는 쌓였어. 위키도 만들었어. **그래서 내가 뭘 더 잘해야 하는데?**"

> "그걸 짚어주려고 이번에 새로 만든 게 **코치**입니다."

**협업 점수 카드 (40초):**
- 큰 점수 **85점 / 등급 B** 가리키며:
> "제 AI 협업 점수, 85점입니다. 세 축으로 나뉘어요."

- 메트릭 바 짚으며:
> "**명확성 99** — 제가 AI한테 의도를 거의 한 번에 전달하고 있다. 오해로 다시 설명한 게 1,056건 중 4건뿐이에요."
> "**거버넌스 100** — Hook 2,283번 실행에서 차단 0건. 규칙이랑 제 작업이 잘 맞는다는 뜻."
> "**꾸준함 57** — 최근에 좀 뜸했죠. 데이터가 정직하게 짚어줍니다."

- **헤드라인** 박스 읽기:
> "그리고 맨 위에 이렇게 떠요. *'지금 협업 흐름이 안정적입니다 — 자산화로 영향력을 키울 차례입니다.'*"
> "이 문장이 오늘 제 발표랑 정확히 같은 말이에요. 개인이 안정됐으면, 이제 자산으로 만들어서 **남들과 나눌 차례**라는 거죠."

**개선 인사이트 (40초):**
- 인사이트 카드들 스크롤하며:
> "그냥 점수만 주는 게 아니라, **다음 한 걸음**을 줍니다."
> "'주 활동 시간대가 16시니까 어려운 작업을 이때 배치해라', '반복 지시는 CLAUDE.md로 정형화하면 토큰 아끼고 일관성 올라간다' — 구체적인 행동으로요."

> 💡 (선택) 점수가 낮은/지저분한 프로젝트면 빨강·주황 경고 카드가 더 많이 뜬다고 한마디:
> "참고로 협업이 막 꼬인 프로젝트에선 빨간 경고가 잔뜩 떠요. 'AI한테 같은 설명 반복 중', 'X 규칙 반복 차단 중' 같은 거. 정직하게요."

**(선택) AI 코치 브리핑 (20초, 키 등록돼 있을 때만):**
- provider 선택 → [브리핑 생성] 클릭:
> "여기 [브리핑 생성]을 누르면, 등록한 LLM 키로 이 인사이트를 사람 말투의 코치 브리핑으로 요약해줍니다. (BYOK라 제 키, 제 비용)"

> ⚠️ 키 없거나 크레딧 0이면 친절한 한국어 안내가 뜸 → **점수+인사이트(룰 기반)는 키 없이도 항상 동작**하므로 브리핑은 스킵해도 데모 깨지지 않음. 이 점을 오히려 강조해도 좋다: "핵심 가치는 LLM 없이도 돕니다."

## 4. 마무리 전환 (15초)

**이동:** 다시 덱으로 (12번 "어떻게 만들었나"부터)

→ 덱 12번부터 이어서 발표 (12 만든 법 → 13 연결 → 14 마무리).

## 실패 대비

- **서버 안 뜸** → 덱 6·8·10번 슬라이드의 UI 재현으로 그대로 설명 (실데이터 동일 수치).

- **코치 점수 안 뜸** → /api/coach/report 응답 확인. 데이터 있는 tenant로 로그인했는지 확인.
- **위키 비어있음** → 빌드는 건너뛰고 덱 8번으로 설명.
