# 프롬프트 금고 (nova-prompt-vault)

잘 동작한 프롬프트를 **재사용 가능한 개인 자산**으로 관리한다. 좋은 프롬프트는 한 번 쓰고 버리는 게 아니라 모아서 다시 쓴다. (커뮤니티 공유 라이브러리와 별개인 "내 금고".)

## 저장 위치

`docs/prompts/<주제>.md` (REPO_ROOT 기준 — Nova 자산 sync 대상). 주제별로 한 파일에 여러 프롬프트를 누적.

## 동작 (요청 의도에 따라 분기)

### A) 저장 — "이 프롬프트 저장해줘"
직전에 효과 좋았던 프롬프트를 받아 아래 형식으로 `docs/prompts/<주제>.md`에 추가:
```
## <짧은 제목>
- **태그**: #리팩토링 #테스트
- **언제 쓰나**: <상황>
- **프롬프트**:
  > <재사용 가능한 형태로 일반화한 프롬프트 본문. 프로젝트 고유값은 [플레이스홀더]로.>
- **메모**: <효과/주의>
```
민감정보·비밀키는 저장 금지(마스킹).

### B) 검색 — "전에 쓴 ~ 프롬프트 찾아줘"
`docs/prompts/` 전체를 훑어 제목·태그·본문에서 매칭되는 프롬프트를 찾아 보여주고, 바로 쓸 수 있게 본문을 제시.

### C) 목록/정리 — "프롬프트 금고 보여줘"
주제별 인덱스(제목 + 태그)를 한눈에. 중복/유사 프롬프트는 병합 제안.

### D) 재사용 — "그거 적용해줘"
저장된 프롬프트를 현재 맥락의 실제 값으로 채워 실행 가능한 형태로 제시.

## 규칙

- 한 번 쓴 좋은 프롬프트는 **일반화**해서 저장(특정 파일명/값 → 플레이스홀더).
- 태그로 분류(#디버깅 #리팩토링 #리뷰 #문서 #설계 등).
- 비밀/민감정보 절대 저장 금지.
- 저장/검색 후 한 줄 요약.
