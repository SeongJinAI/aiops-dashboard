# 백엔드 규칙

## 구조

- `server/main.py` — FastAPI 앱 진입점, WebSocket, lifespan에서 DB 초기화 + 파일 감시
- `server/routers/` — logs, projects, health, repos
- `server/services/database.py` — SQLite 영구 저장 (prompts, hook_logs, workflow_checkpoints 테이블)
- `server/services/log_reader.py` — JSONL 파일 파싱
- `server/services/project_swap.py` — 테스트 레포 .env 수정 + setup.sh 실행
- `server/services/repo_scanner.py` — 레포 스캔

## 데이터 흐름

```
JSONL 파일 (logs/{hooks,prompts,workflow}/{YYYY-MM-DD}.jsonl)
  │
  ├── 서버 시작 시 → SQLite로 일괄 import (import_existing_jsonl)
  ├── watchfiles 감시 → 새 줄 추가 시 DB 삽입 + WebSocket push
  │
  ├── REST API (GET /api/logs/*) → JSONL 직접 읽기
  └── WS /ws/logs → 실시간 스트림
```

## API 엔드포인트

상세 API 명세는 `dashboard-구현-가이드.md`의 "API 엔드포인트" 섹션 참조.

## 실행

```bash
cd server
uvicorn main:app --reload --port 8000
```
