# 백엔드 규칙

> 제품 = **Nova**(개인 AI 코칭 SaaS). Python 3.11+ / FastAPI · SQLAlchemy(async). 현행 개요는 `CLAUDE.md`, 세션 기록은 `HANDOFF.md`.

## 구조

- `server/main.py` — FastAPI 진입점. 라우터 등록 + lifespan(DB `init_db` + 파일 watcher) + WebSocket(`/ws/logs`) + **중앙 예외 핸들러**(4xx=warning / 5xx=error 자동 로깅).
- `server/routers/` — `auth` · `coach` · `chat`(RAG 지식 챗) · `library` · `billing` · `hermes`(위키) · `secrets` · `projects` · `repos` · `ingest` · `scripts`(install.sh + skill 번들) · `assets`(자산 sync) · `claude_config` · `health` · `logs`.
- `server/services/` — 비즈니스 로직. `coach` · `rag` · `prompt_library` · `managed_llm`(BYOK 우선→관리형+쿼터) · `usage`(쿼터) · `billing` · `secret_store`(AES-256-GCM) · `crypto` · `errors`(`E`/`err` 레지스트리) · `db` · `database`(async engine/session) · `log_store`(`AIOPS_MODE` 분기) · `log_reader` · `misunderstanding_detector` · `secret_masker` · `rate_limit` · `env_check` · `event_bus` · `hermes/`(catalog·wiki_builder·diff·llm_client) · `llm/`(base·registry·anthropic/openai/gemini provider).
- `server/models/db_models.py` — 전체 ORM 테이블(tenants/users/logs/projects/assets/doc_chunks/tenant_secrets/subscriptions/llm_usage/prompt_templates/hermes_*).
- `server/middleware/auth.py` — `get_current_user`(JWT) · `get_tenant_flexible`(JWT 또는 X-API-Key) · `require_premium`(402).
- `server/scripts/hooks/*.sh`(활동 수집) · `server/scripts/skills/*/SKILL.md`(문서 생성 skill 번들).

## 데이터 흐름

```
Track(수집): Claude Code Hook → POST /api/ingest
  → secret_masker(11종 마스킹) → services/db.insert_log → logs 테이블
  → event_bus.publish → /ws/logs 실시간 스트림
  → (prompts/hooks면) misunderstanding_detector 자동 오해 감지

조회: services/log_store가 AIOPS_MODE로 분기
  - saas  → services/db.query_logs (DB)
  - local → services/log_reader (JSONL 직접, watchfiles 증분)
```

DB: **DATABASE_URL 우선(postgresql+asyncpg, 운영) → 없으면 DB_PATH SQLite 폴백(dev)**. `init_db`는 create_all 멱등 부트스트랩(운영은 `alembic upgrade head`).

## 핵심 규칙

- **예외 4계층**: 요청검증 400 / 인증인가 401·402·403 / 비즈니스 404·409 / 외부의존·시스템 503·500. 에러는 **`services/errors.py`의 `E`/`err`로** raise(문자열 리터럴 금지). 로깅은 중앙 핸들러가 자동(4xx=warn/5xx=error).
- **계층**: 라우터는 얇게(검증+위임), 비즈니스는 service. 도메인 상태 변경은 모델/엔티티가.
- **async 일관**: secret_store·provider.load_key 등 모두 async — `await` 누락 주의.
- LLM은 `managed_llm.complete`로 라우팅하면 BYOK 우선→관리형(쿼터). hermes만 직접 provider(BYOK).

## 실행

```bash
cd server
# dev (SQLite 폴백, --reload 미사용 — WebSocket graceful shutdown 이슈)
AIOPS_MODE=saas DATABASE_URL= DB_PATH=./data/aiops_saas.db \
  python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
# 재시작: pkill -9 -f "uvicorn main:app"
```

운영은 `docker-compose.cloud.yml`(postgres + `alembic upgrade head` → uvicorn + nginx). 배포 전 `AIOPS_ENV=prod`로 시크릿 가드 활성(JWT_SECRET/HERMES_MASTER_KEY 강제).
