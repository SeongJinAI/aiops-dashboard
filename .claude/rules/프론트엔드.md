# 프론트엔드 규칙

## UI 디자인 원칙

`dashboard-architecture.jsx`의 컬러, 레이아웃, 컴포넌트 구조를 그대로 따른다. 임의 변경 금지.

## 컬러 팔레트

`frontend/src/constants/colors.ts`의 `C` 객체를 사용한다. 하드코딩된 색상값 사용 금지.

## 구조

- `frontend/src/pages/` — 6개 페이지 (RepoMap, ProjectSwap, SystemStatus, HookMonitor, WorkflowTracker, PromptHistory)
- `frontend/src/hooks/useWebSocket.ts` — WebSocket 실시간 연결
- `frontend/src/hooks/useApi.ts` — REST API fetch wrapper
- `frontend/src/constants/repos.ts` — REPOS, CONNECTIONS 상수
- `frontend/src/types/index.ts` — 공유 TypeScript 타입

## Vite 프록시

개발 시 `/api` → `localhost:8000`, `/ws` → `ws://localhost:8000`으로 프록시 (vite.config.ts).
