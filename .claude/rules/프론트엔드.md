# 프론트엔드 규칙

> Vite · React 19 · TypeScript. 디자인 SSOT는 `DESIGN-BRIEF.md`. 현행 개요는 `CLAUDE.md`.

## UI 디자인 원칙 (DESIGN-BRIEF.md 준수)

- **자체 oklch 디자인 토큰** — `frontend/src/styles/tokens.css`의 `var(--…)`만 사용.
- **금지**: 인라인 `style={{}}`, 하드코딩 색(#hex), 이모지 UI(✓×⬇ 등). → `ui/primitives` 컴포넌트 + CSS 토큰으로.
- 숫자는 `tabular-nums`(mono). 빈 상태는 정직하게(가짜 데이터/가짜 진행 금지).
- light/dark + density(compact/normal/roomy)는 토큰으로 자동. localStorage 영속.
- (legacy) `constants/colors.ts`의 `C` 객체는 구식 — 미마이그레이션 보조 페이지(OnboardingWizard 등)에만 잔존, 신규 코드는 토큰 사용.

## 구조

- `frontend/src/pages/` — Landing · Login · Home · Coach · Chat(지식 챗) · Prompts · Misunderstandings · HookMonitor · Library(Pro) · Subscribe · Agent(위키) · Connections · ProjectSwap · OnboardingWizard.
- `frontend/src/app/` — `AppShell` · `Sidebar`(3섹션) · `TopBar` · `CommandPalette`(⌘K).
- `frontend/src/ui/` — `primitives.tsx`(Box/StatCard/Chip/Btn/EmptyState/Skeleton/Avatar) · `Icon.tsx`(lucide) · `toast.tsx`.
- `frontend/src/constants/nav.ts` — IA(코칭 / 에이전트·계정 섹션).
- `frontend/src/hooks/` — `useApi`(REST + 401 처리) · `useWebSocket`(실시간) · `useAuth`.
- `frontend/src/styles/` — `tokens.css` · `ui.css` · `landing.css`.

## 라우팅 / 인증

- `App.tsx`: 미인증 시 `authView`(landing↔auth) 분기 → 인증 후 **path 기반 switch 라우팅**(현재 URL/history 미연동 — useState 기반).
- `apiBase`: `inferInitialApiBase()` — 5173/5174(vite dev)면 8000으로 보정.

## Vite 프록시 (vite.config.ts)

개발 시 `/api` → `localhost:8000`, `/ws` → `ws://localhost:8000` (`changeOrigin: true`). WSL HMR은 `server.watch.usePolling`로 폴링(`/mnt/c` fs.watch 미동작 대응).

## 검증

변경 후 `npm run build`(tsc -b && vite build)로 타입 0 에러 확인.
